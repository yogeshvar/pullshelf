Questions

Is Pullshelf free?

Yes. Pullshelf is open source under the MIT license. You can build it yourself, install it with Homebrew, or download the zip, at no cost. There are no paid tiers, locked features or accounts.

Which Macs does it run on?

Apple Silicon Macs running macOS 13 or newer. An Intel build is not available yet.

Why does macOS warn me on first launch?

Pullshelf is ad-hoc signed but not yet notarized by Apple. On first launch, open it once, then go to System Settings, Privacy & Security, and choose Open Anyway. Notarization is planned.

What does it send over the network?

Nothing. There is no telemetry, no account and no cloud sync. Your clips, notes and file references stay in a local database on your Mac.

Why does it ask for Accessibility permission?

Only the pull-down gesture needs it, to read two-finger scrolls at the top screen edge. You can skip it and open Pullshelf with ⌘⇧L or from the menu bar icon.

Does it work with Claude Code or Codex?

Yes. The terminal pane can start your shell, Claude Code or Codex, and you can send a clip or note straight into it.
