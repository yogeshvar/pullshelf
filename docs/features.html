Features

What's on the shelf

Terminal

A real terminal in the shelf. Start your shell, Claude Code or Codex. Send a clip or a note into it. Your session keeps running while the shelf is hidden.

Clipboard

History of text and images, newest first. Search, favourite, copy back, or send to the terminal. Clear it any time.

Files

Drop files and folders as references (nothing is copied or moved). Open, reveal in Finder, or drag them back out.

Notes

A distraction-free scratchpad with a list, search and renaming. Saved as you type and mirrored as Markdown files.

The shelf itself

Pull from the top edge or press ⌘⇧L. Drag the bottom edge to set its height, drag dividers to resize panes, collapse any pane to a rail. Light and dark themes.

Menu bar and settings

Launch at login, hide or show the menu bar icon, scroll gesture status, quit.

Pullshelf

A pull-down shelf for the Mac.
